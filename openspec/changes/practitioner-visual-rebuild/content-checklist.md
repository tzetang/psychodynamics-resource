# Content checklist

Run every situation and concept through this before it ships. Each line is a yes/no.

Reviewed 2026-10-21 against all 10 situations and 15 concepts (task 8.1). One fix: the `valency` concept's definition and examples were reworded so they describe a role the group hands out, not a kind of person. A scan for clinical or diagnostic terms found none outside sources. This is the author's own review; a domain reviewer (coach or organizational consultant) has not yet looked at it (see the open question in `design.md`).

## Dynamics, not diagnoses
- [x] Every caption describes what happens between people or in a role. No caption says what a person *is*.
- [x] No clinical or diagnostic label is applied to an individual ("she is splitting", "he is narcissistic").
- [x] Concept definitions describe a pattern that can happen to anyone. None invites the reader to classify a specific colleague.
- [x] Actors are unnamed glyphs or plain roles ("a report"). No scene casts a type of person as the problem.

## Everyday language
- [x] A manager with no psychology background can read every caption aloud without a term needing explaining.
- [x] Any academic term appears only in the collapsed "Where this comes from" expander or after its plain version.
- [x] Situation titles are phrased the way a leader would say it ("Everyone waits for me to decide").

## Every motion is captioned
- [x] Each beat's caption says what the viewer is seeing change (movement, haze, orbs).
- [x] No animation is there for decoration. If a motion has no captioned meaning, cut it.
- [x] Orbs are explained by caption or by the "Feelings moving" line; colour is never the only signal.
- [x] The reduced-motion storyboard reads correctly from the captions alone.

## Stances are the leader's own
- [x] Every scene has a "your part" beat showing how the leader feeds or joins the dynamic.
- [x] Each Try is written as what *you* do ("You ask, 'What would you do?'"), never as a technique applied to someone.
- [x] The after version shows a visibly different arrangement or flow, not just a thinner haze.

## Limits and safety
- [x] The situation has a visible "When this is more than a team dynamic" note naming signals for HR, a coach or a mental-health professional.
- [x] Each concept page carries the "what this picture leaves out" line.
- [x] Sources (theorists, key work, year) are present and correct, and collapsed by default.
- [x] The situation has 1–2 knobs with plain labels and low/high end labels.
